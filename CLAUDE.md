# SmallGame

A small game project. It has nothing to do with EnvRebuild (`E:\P4\EnvRebuild`): never read,
change or depend on that folder from here.

## The game

- Genre: a backpack / inventory-management game (in the spirit of Backpack Hero and Backpack
  Battles). Items have shapes and fit on a grid backpack; where you place them decides how
  well you fight. It is our own original game: our own items, rules, names and art, not a
  copy of either game.
- Played in a web browser.
- Tool: plain HTML + JavaScript, no library and no install. Open the page in a browser to play.
- Start tiny: one backpack, a few items, one fight, then grow from there.
- Fights are automatic: the player arranges the backpack, then items act on their own
  (on timers) while the fight plays out. Between rounds there is a shop to buy new items
  and rearrange the backpack.
